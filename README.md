# Разбери ми документа

Начална версия на уеб приложение за проекта за НОИТ 2027. Целта е официалните PDF документи да станат по-лесни за разбиране чрез извличане на изисквания, срокове и следващи задачи.

В тази версия страницата е демонстрационна: изборът на файл показва името му само в браузъра. Файлът не се качва и не се анализира. AI анализът и съхранението на данни ще бъдат добавени на следващ етап.

## Необходими инструменти

- Node.js и npm

## Инсталиране

Отворете терминал в папката на проекта и изпълнете:

```bash
npm install
```

Това инсталира Express и необходимите му зависимости.

## Стартиране

```bash
npm start
```

После отворете [http://localhost:3000](http://localhost:3000) в браузъра. Спрете сървъра с `Ctrl+C` в терминала.

## Основни файлове

- `server.js` — стартира Express сървъра и обслужва статичните файлове от `public/`.
- `public/index.html` — структурата и текстът на началната страница.
- `public/styles.css` — цветовете, оформлението и адаптивният изглед.
- `public/script.js` — показва името на избрания PDF файл в браузъра; не го качва.
- `package.json` — настройките на проекта, пакетът Express и командата `npm start`.
- `.gitignore` — файлове и папки, които не трябва да се добавят към Git.
