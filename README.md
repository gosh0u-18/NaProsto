# НаПросто

**Опростяваме сложните документи.** НаПросто извлича текст от PDF или снимка и обяснява на български изискванията, сроковете и следващите действия. Показва оригиналния цитат и страницата, за да можеш да провериш отговора.

## Бърз старт

Нужни са **Node.js 24**, npm и Git. Изпълни командите в папката на проекта:

```bash
npm ci
```

Създай локалните настройки от примера:

```powershell
Copy-Item .env.example .env
```

На Linux/macOS използвай `cp .env.example .env`. После:

```bash
npm start
```

Отвори http://localhost:3000. Спиране: `Ctrl+C`. Ако PowerShell блокира npm, използвай `npm.cmd` вместо `npm`.

Без API ключ работят PDF извличането и OCR на снимки. AI анализът е изключен по подразбиране. `npm ci` подготвя локалните OCR модели чрез `postinstall`. Ако е необходимо, изпълни `npm run prepare:ocr`.

## Включване на Gemini

Промени само локалния `.env`:

```dotenv
AI_MODE=gemini
AI_ENABLE_REAL_REQUESTS=true
GEMINI_API_KEY=постави_своя_ключ_тук
GEMINI_MODEL=gemini-3.5-flash-lite
AI_TIMEOUT_MS=30000
PORT=3000
```

Използвай модел, достъпен за твоя акаунт; примерното име не гарантира достъп или безплатна квота. Рестартирай сървъра след промяна. Ключът се използва само от backend. Не го поставяй в `public/`, README, GitHub или съобщения.

Реалните заявки могат да използват платена или безплатна квота според настройките на доставчика. AI заявката започва след изрично съгласие от страницата. Повторният анализ е нова заявка. За локална демонстрация без външни заявки използвай:

```dotenv
NODE_ENV=development
AI_MODE=mock
AI_ALLOW_LOCAL_MOCK=true
AI_ENABLE_REAL_REQUESTS=false
```

Mock режимът е само за локален тест, не за публичен сървър. Има и backend клиент за OpenAI; настройките са в `.env.example`. Смяната на ключа между различни доставчици не е достатъчна — избери правилния `AI_MODE`.

## Как се използва

1. Избери PDF или снимка, пусни файл в зоната или използвай камерата на телефона.
2. Прегледай извлечения текст. При снимки сравни важните стойности с изображението.
3. Ако AI е включен, дай съгласие и натисни „Анализирай документа“.
4. Прегледай обобщението, предупрежденията и цитатите. Избери своята роля за личните задачи.
5. Изтегли пълния JSON или избери „Печат / PDF“. Печатът позволява избор на обобщение, задачи и цитати; предупрежденията остават включени.

Намереният цитат доказва, че откъсът присъства в текста, а не че AI го е изтълкувал правилно. При непълен резултат се показва частичен статус. Грешен срок може да доведе до пропускане на конкретна находка; валидните останали находки се запазват с предупреждение. Невалидната структура на отговора отхвърля цялата част.

## Тестове

Първо можеш да изпълниш малка, по-лесна за проследяване група:

```bash
npm run test:basic
```

Всички проверки, включително PDF, OCR, API, интерфейс и печат:

```bash
npm test
```

Тестовете не зареждат локалния `.env` през `server.js`, а създават тестово приложение. Използват mock отговори или подменен HTTP клиент; конфигурираният реален AI е изключен в тестов процес. Не са нужни API ключове и не се правят платени заявки. `tests/fixtures/bulgarian-photo.png` е тестова снимка и трябва да остане в проекта.

GitHub Actions изпълнява `npm ci`, проверката за публикуване и всички тестове с Node.js 24 на Linux. Локално може да ги изпълняваш и на Windows. Реалният GitHub workflow трябва да мине след първото качване; локалното изпълнение не доказва, че hosted средата вече е проверена.

## Ограничения и данни

- Един файл до **10 MB**; до **100 PDF страници** или една JPEG/PNG/WebP снимка до **12 мегапиксела**.
- PDF: до **100 000 символа на страница**, до **1 000 000 общо**. Проверяват се сигнатурата и реалното отваряне. DOC/DOCX и PDF с парола не се поддържат.
- AI: до **4 заявки**, **16 000 входни символа**, **4000 символа на част** и **4000 изходни токена на заявка**. Отговорът е ограничен до 256 000 байта; до 200 находки общо.
- До **30 секунди за AI заявка**, **60 за целия AI анализ**, **90 за цялата обработка**, **95 за изчакване в браузъра**. PDF/OCR процесът остава до 15 секунди и 128 MB JavaScript heap. Това не е пълен лимит за нативната/WASM памет.
- До **2 едновременни обработки**, **6 опита за анализ на минута** и **12 AI заявки на минута за един сървърен процес**. Няма автоматични повторения. Броячите са в паметта, общи за посетителите и се нулират при рестарт.
- Качените файлове са временно в паметта. Няма база данни или постоянен архив на документите. Статичният PWA кеш не съхранява API отговори или качени файлове.
- При AI анализ извлеченият текст се изпраща на избрания доставчик. Неговите правила за съхранение и използване на данните зависят от услугата и плана.
- OCR е за отделна снимка, не за всички страници на сканиран PDF. Сложни таблици, подредба на текст и OCR грешки могат да намалят точността. Срокове не се изчисляват по предположение.

## Подготовка за GitHub

```bash
npm run check:release
npm test
git status --short
```

Качват се кодът, тестовете, документацията, `.github/`, `.gitignore`, `.env.example`, `package.json` и **`package-lock.json`**. `private: true` в package.json предотвратява случайно публикуване в npm; не пречи на публично GitHub хранилище.

`.env`, `node_modules/`, временните документи, отчетите, кешовете и локалните бази са изключени чрез `.gitignore`. Проверяващият скрипт открива познати формати на ключове и забранени файлове, без да отпечатва тайните стойности. Той не гарантира липсата на всички видове тайни и не проверява цялата Git история. Прегледай промените преди commit. Ако ключ някога е публикуван, отмени го и създай нов.

Проектът не избира лиценз вместо автора. Преди да разрешиш свободно преизползване на кода, избери подходящ лиценз и добави `LICENSE`. Публичното хранилище само по себе си не задава отворен лиценз.

## Публичен сайт

GitHub съхранява кода. За цялото приложение е нужен хостинг, който изпълнява **Node.js/Express**; GitHub Pages не изпълнява този backend.

Настройки за Node.js хостинг:

- Node.js **24**.
- Команда за инсталиране: `npm ci` (без пропускане на `postinstall`).
- Команда за стартиране: `npm start`.
- Проверка за работещ сървър: `GET /health`.
- `NODE_ENV=production`; `PORT` се задава от хостинга.
- Въведи AI настройките като тайни environment variables на хостинга, а не като файлове в GitHub. За публична демонстрация само на извличането остави `AI_MODE=disabled` и `AI_ENABLE_REAL_REQUESTS=false`.
- Използвай HTTPS, достатъчно памет за OCR и HTTP timeout над 90 секунди. Камерата и PWA изискват сигурен контекст, освен при localhost.

Провери качване, OCR, AI, повторен анализ и печат върху публичния адрес. Google Fonts изтегля шрифта от Google; без достъп се използва Arial.

**Преди неограничен публичен AI достъп:** приложението няма потребителски акаунти, устойчив дневен бюджет или защита, обща за няколко сървърни инстанции. Посетителите могат да използват квотата на собственика през backend, без да виждат ключа. За такъв достъп са нужни ограничения при хостинга/доставчика и при необходимост контрол на достъпа. Текущите минутни лимити не са гаранция за разходите. Тази подготовка не е автоматично публикуване или одит за производствена среда.
